# shadow-options-trading-lab v0.1.1 — Linux research runner

## What changed

- Linux Docker deployment for the strategy lab runner with persistent runtime output.
- Audited strategy, snapshot and error handling repairs.
- Deployment archive contains tooling and configuration examples, without local ledgers or credentials.

## Install and upgrade

Back up runtime and private configuration before upgrading. Containers default to displaying help; explicitly start a shadow run with your own configuration. Vision scouting needs the optional browser image target. No broker orders are placed.

See [deployment instructions](https://github.com/csnyder256/shadow-options-trading-lab/blob/v0.1.1/DEPLOYMENT.md) and the attached checksums.
