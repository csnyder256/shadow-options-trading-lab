# v0.2.0 - Traceable historical replay

## Changes

- Added an offline interactive replay viewer using the current exit engine and frozen V1 baseline, with play, scrub, quote charts and a complete four-step tour.
- Added per-mark input and decision traces, closed-only paired dollars and exit timing, explicit open/unreplayable coverage, configurable fees, JSON/CSV exports and printable reports.
- Added an invented archived-date XYZ demonstration, input validation, source/input/parameter hashes and a per-file output manifest. The demo requires no account or network.
- Kept the existing replay result contract unchanged; decision tracing is optional. Private configuration and signal notes are excluded from reports.

## Install and upgrade

Download the standalone `index.html` for the fictional demonstration, or the versioned deployment bundle to run your own ledgers. Back up personal ledgers and keep the previous release for rollback. [Deployment and upgrade guide](https://github.com/csnyder256/shadow-options-trading-lab/blob/v0.2.0/DEPLOYMENT.md).

## Interpretation

The fictional paths are not market results. The report studies exit policies for selected entries, with ask-to-bid fills and fees; it does not model a full trading strategy, market impact, assignments or portfolio returns. Missing context and open positions stay unavailable in realized results.
